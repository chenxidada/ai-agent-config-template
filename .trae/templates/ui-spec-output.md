# UI Spec Output Template

<!--
  此模板由 requirement-analyst 在探测到 UI 相关性（ui_relevant: true）时使用。
  输出：<spec_dir>/ui-spec.md + <spec_dir>/ui-spec-zh.md

  存在意义：EARS 验收标准只能表达「行为」，表达不出「长什么样」。
  本文件补上「界面长什么样」这一层,是 implementer / reviewer-visual / verifier 的共同 ground truth。

  ═══════════════════════════════════════════════════════════════════
  🔴 铁律一：禁止抽象形容词
  ═══════════════════════════════════════════════════════════════════
  UI 需求必须给出「可验收的具体值」。以下词汇一律禁止单独出现：
    美观 / 现代 / 简洁 / 大方 / 优雅 / 流畅 / 高级感 / 科技感 /
    响应式适配 / 体验好 / 交互友好 / 布局合理 / 颜色协调

  ❌ 反例：「界面简洁现代，响应式适配移动端」
  ✅ 正例：「主色 #2563EB，卡片圆角 12px，区块间距 24px，正文 14px/1.5，
           表格行高 44px；375px 下侧栏折叠为抽屉（宽度 280px 覆盖式），
           768px 及以上侧栏常驻（宽度 240px）」

  规则：若某条 UI 需求无法写出具体值 → 必须放入「待澄清项」，不得用形容词蒙混过关。

  ═══════════════════════════════════════════════════════════════════
  🔴 铁律二：布局必须有 ASCII 骨架
  ═══════════════════════════════════════════════════════════════════
  每个页面至少给出桌面 + 移动两份 ASCII 布局骨架。
  纯文字描述布局必然产生歧义（「左边放侧栏」——多宽？可折叠吗？与内容区谁滚动？）。
  ASCII 骨架是让 implementer 不再即兴发挥的最低成本手段。

  ═══════════════════════════════════════════════════════════════════
  🔴 铁律三：状态必须穷举
  ═══════════════════════════════════════════════════════════════════
  「列表页」不是一个状态，而是 default / loading / empty / error / disabled 等多个状态。
  未写明的状态由 implementer 即兴发挥 —— 这正是偏差的主要来源。
-->

## 5. 交互状态矩阵

<!--
  🔴 必填。每个页面（或每个数据驱动组件）穷举状态。
  「未实现」也要显式写出来，否则会被当作「应该实现」而被漏掉。

### P-1 用户列表页

| 状态 | 触发条件 | 界面表现 | 是否必须实现 |
|------|------|------|:--:|
| default | 数据加载完成且非空 | 表格显示 N 行 + 分页控件 | ✅ |
| loading | 首次加载 / 翻页中 | 表格区域显示骨架屏（3 行灰条），保留表头 | ✅ |
| empty | 加载完成但结果为空（无筛选） | 居中插图 + 文案「暂无用户」+ [新建用户] 按钮 | ✅ |
| empty-filtered | 搜索/筛选后无结果 | 文案「未找到匹配「{关键词}」的用户」+ [清除筛选] | ✅ |
| error | 请求失败 | 表格区域显示错误文案 + [重试] 按钮 | ✅ |
| disabled | 无权限用户 | 新建/编辑按钮置灰，tooltip 提示无权限 | ❌ 本 Phase 不做 |

**行级状态**：

| 状态 | 表现 |
|------|------|
| hover | 行背景 `bg-slate-50`，`cursor-pointer` |
| focus | 行可键盘聚焦，2px 主色 outline，offset 2px |
| deleting | 该行内容降为 40% 不透明，操作按钮替换为 spinner |

### P-2 新建用户弹窗

| 状态 | 触发条件 | 界面表现 | 是否必须实现 |
|------|------|------|:--:|
| default | 打开 | 表单为空，焦点落在「姓名」输入框 | ✅ |
| validating | 失焦后校验失败 | 字段下方红字错误提示，边框转红 | ✅ |
| submitting | 点击保存后 | 保存按钮进入 loading，禁用，不可重复提交 | ✅ |
| error | 提交失败 | 弹窗内顶部错误横幅 + 保留已填内容 | ✅ |
